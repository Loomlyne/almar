Plumbing that undermines the system

• Nav, dashboard and footer load the wordmark and monogram from framerusercontent.com. The SVGs are already in brand/. If the Framer project goes, the logo goes.
• next.config.js and next.config.mjs both exist. Next loads the .js one, so the SVG rule in .mjs never runs.
• Tailwind v4 is imported but used about 20 times; everything else is global classes plus 1,388 lines of CSS modules. Pick one method.
• The React shell's nav and the Framer page underneath are two copies of the header. Two sources of truth for every menu, logo and link.
