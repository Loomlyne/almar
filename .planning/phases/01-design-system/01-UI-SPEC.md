> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

Phase 1 ships tokens, core controls, RTL states, a dev-only `/design` kit, and a branded 404. Booking screens are not built. Locked visuals from CONTEXT.md are specimens on `/design`. ## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 400 | 1.4 |
| Heading | 32px | 400 | 1.1 |
| Display | 48px | 400 | 1.1 |

Exactly four sizes. Exactly two weights: 400 and 700.

- 400 is the weight of every role above. Questa has Regular only. Do not synthesize a Questa bold.
- 700 is Lato only. The only use is the grand-total amount, at the heading size (32px) so “larger” does not add a fifth size.
- Italic is a style of Lato 400, not a third weight. Load Lato Regular, Lato Italic, and Lato Bold only. Do not load Hairline, Thin, Light, Medium, Semibold, Heavy, or Black.
- Display and heading tracking: `-0.02em`. Body and label tracking: `0`.
- Inputs are the label size (14px) from `md` up and the body size (16px) below `md`, so iOS does not zoom. Other UI text stays at the label size on desktop.

| Empty state heading | No stays for these dates |

Voice: calm, plain, no humor on errors. Address the reader as “you” only where a locked string already does. Sentence case for contract copy. Locked strings keep their locked case.

| Token | Value | Use |
|-------|-------|-----|
| Fast | 150ms | Hover, press, color, opacity. High-frequency. |
| Mid | 250ms | Overlay opacity enter and exit. |
| Slow | 400ms | Not used on controls. Do not stagger the kit. |

## Interaction and a11y

- Native `<button>`, `<a href>`, and `<input>` / `<textarea>` / `<select>` behavior. No `<div onClick>`. Links support modified clicks.
- `:focus-visible` ring: 2px solid `--color-focus`, offset 2px. Never `outline: none` without this replacement. Do not restyle mouse `:focus` in a way that removes `:focus-visible`. In `forced-colors: active`, the ring is `CanvasText`.
- Input focus uses that ring. The hairline border does not change color (D-56).
- Hit target: 44px minimum on every control, both densities, including icon buttons, stepper buttons, the eye, close, and chips. Extend with a pseudo-element when the visible mark is smaller. Extended hit areas must not overlap. Decorative layers use `pointer-events: none`.
- Placeholder is never the label. Label sits above the field, always visible (D-28).
- Required: charcoal asterisk after the label. Optional fields say `optional` (D-57).
- Hint: label size, charcoal, under the field. Error replaces the hint in `--color-danger` (D-71). `aria-invalid="true"`. `aria-describedby` points at the error. Validate on submit, then as the field is fixed (D-159). Focus the first invalid field. Submit stays enabled until the request starts.
- Disabled: same shape, muted border and label, no gold, `cursor` is not a pointer, native `disabled` (D-16, D-157). Text uses `--color-muted-fg`, not opacity. A disabled stepper shows its reason in text beside it, not in a tooltip.
- Do not block paste.
- Skip to content is the first focusable element on `/design`, the 404, and the server error. Copy: `Skip to content`. Visible on focus. Teal ring.
- One `<h1>` per page. Heading levels do not skip.
- 200% zoom and 320px width reflow with no horizontal scroll. No `maximum-scale` in the viewport meta. Text containers use `min-height`, not a fixed height.
- `lang` and `dir` live on `<html>`, not on a wrapper. Default `lang="en"` `dir="ltr"`.
- Color is never the only status cue. Pair it with text or an icon.
- Toasts: `role="status"` for non-urgent lines. `role="alert"` for errors. Every toast dismisses at 4 seconds and pauses on hover or focus (D-27). A dismiss control is still present. A stable empty status region exists before its text updates.
- Dialogs: Radix focus trap, `inert` on the background, focus moves inside on open, returns to the trigger on close, `overscroll-behavior: contain`.
- Select listbox: Radix. Arrow keys, typeahead, and active descendant stay Radix. Visuals stay custom. Empty list is one charcoal line: `No options to show`. No fake options (D-98).
- Calendar math: `@internationalized/date`. Do not mount a React Aria calendar UI. Week starts Monday. Days outside the month are hidden. Empty cells pad the grid (D-78).
- Specimens do not submit. No `dangerouslySetInnerHTML`. Icons are source files, not uploaded SVG.

## Layout

- Content column max-width: 1240px, centered (D-58).
- Column inset: 16px below `md`, 32px from `md`, 64px from `lg`. These are spacing tokens. The export’s larger page inset is not a token.
- Breakpoints: Tailwind defaults. Do not add a custom breakpoint. Small-screen behavior starts below `md` (768px): stacked booker, monogram, full-width primary button, end drawer, stacked footer, stacked newsletter row.
- Logical properties only in `components/`: `margin-inline`, `padding-inline`, `inset-inline`, `text-align: start`, `text-align: end`. No `margin-left`, `padding-right`, `left`, `right`, `text-left`, or `text-right`.
- No fixed width on text that will translate. Rows wrap. Long names: two lines, then ellipsis. Prices never truncate.
- Group with space first. Gap inside a group is one spacing step. Gap between groups is at least double. Gold rules separate page sections only (D-47, D-93). Price lines use a charcoal hairline, not a gold rule.
- Controls are visually distinct from static text: fill, border, or a stable chrome zone.
- Backgrounds and media may bleed. Controls and text stay inside the inset and `env(safe-area-inset-*)`, except the small-screen drawer, which is full viewport width (D-95).
- Sticky header: solid ivory, hairline under it, no shadow, no shrink, no hide on scroll (D-65, D-150). z-index 40.
- Layer order, top first (D-66): modal and drawer 70, WhatsApp 60, toasts 50, sticky header 40.
- WhatsApp: fixed, `inset-inline-end` 16px plus safe area, `bottom` 16px plus safe area, 44px circle, above toasts (D-44).
- Toasts: bottom center, bottom offset 64px so they clear the WhatsApp control, stack up to 3, gap 8px, newest closest to the bottom (D-27).
- Dialog actions: dismiss at inline-start, primary at inline-end (D-96). The row flips with `dir`.
- Overlay close: inline-end of the header (D-51). End flips in Arabic.
- Stay-row image: inline-start, 4:3, cover (D-48). Start flips in Arabic.
- Sign-in split specimen: image on inline-start, form on inline-end (D-128).

## Type behavior

- `text-wrap: balance` on headings and display. `text-wrap: pretty` on descriptions. `overflow-wrap: break-word` on refs, emails, and long tokens. `white-space: nowrap` on chips and the booking ref.
- `font-variant-numeric: tabular-nums` on prices, dates, counts, nights, refs, and the hold countdown. Western numerals always. If `Intl` is called for Arabic, use `ar-AE-u-nu-latn`. No Arabic-Indic digits.
- Long text measure: `65ch`.
- Root: `-webkit-font-smoothing: antialiased` and `-moz-osx-font-smoothing: grayscale` once on `<html>`.
- `::selection`: gold background, teal text (6.37:1). Text stays selectable. Do not set `user-select: none` on the page.
- Underlines are not used on links (D-45). If a legal link inside a checkbox label needs a cue, use a teal text link with the focus ring, still no underline.
- Dates render `DD/MM/YYYY`. Ranges use an en dash: `23/09/2026–30/09/2026`.
- Amounts: currency code, space, number. Comma thousands. Two decimals only when not whole. `AED 1,050` and `AED 1,240.50`. Code before the number (D-50).
- Fonts, via `next/font`:
  - Questa: `brand/Font/questa-webfont/2-Questa_Regular.woff`, weight 400, variable `--font-questa`, fallback Georgia, serif.
  - Lato: Regular 400, Italic 400, Bold 700 from `brand/Font/lato/`, variable `--font-lato`, fallback Arial, sans-serif.
  - Arabic, only while the preview language is AR: `Noto_Naskh_Arabic` weight 400 for headings, `Noto_Sans_Arabic` weights 400 and 700 for UI. Do not load them on EN or ES.
- Display and headings use the display font. Body, UI, forms, prices, and refs use the body font. Refs are never gold (D-118).
- Compact density (`data-density="compact"`): padding drops one spacing step. Type stays on the four sizes. Hit target stays 44px. Same palette (D-03, D-62).

## Component contracts

### Link

Teal, no underline, gold on hover, teal focus ring (D-14, D-45). Real href. No loading state. Disabled is not a painted link; omit it or use `aria-disabled="true"` with no navigation, labeled N/A for loading, error, and empty.

Back is a text link at inline-start, not a gold button (D-113). Copy: `Back`.

### Button

| Variant | Fill | Border | Label | When |
|---------|------|--------|-------|------|
| Primary | gold | none | teal | The one gold action in that view |
| Secondary | transparent | 1px teal | teal | Search, Apply, Subscribe, Request |
| Ghost | none | none | teal, gold on hover | Text actions that are not links |
| Danger | none | 1px `--color-danger` | charcoal | Sign out, delete confirm, cancel-booking confirm |

Min-height 44px. Radius 40px. Padding inline 24px. Below `md`, primary is the full width of the column (D-63). Compact density: the button hugs the label, hit target still 44px.

Hover: primary fill `--color-accent-hover`. Press: `--color-accent-press`. 150ms. No scale. Disabled primary is not gold.

Busy: spinner at inline-start, label unchanged, `disabled`.

### Field
