## What was built

- **API** `app/api/ops/media/route.ts` (force-dynamic, owner + Origin check through `opsGet`/`opsPut`/`opsPost`):
  - `GET ?q&after&limit`: reads `ops_list('media')`, sorts by key then id, filters `q` over the key and the EN alt,
    pages by `after` = last key; a page never ends between two rows of the same key; returns `next`.
  - `PUT` (raw body, headers `content-type`, `x-almar-sha256`, `x-almar-width`, `x-almar-height`, `x-almar-alt-en`):
    JPEG/PNG/WebP only (415), 15 MB (413), `FixedLengthStream` so the length is enforced, key
    `uploads/<first 32 hex of sha256>.<ext>`, `head` before `put` (never overwrites), `put(..., { sha256 })` so R2
    checks integrity; refused digest -> 400 `invalid`/`sha256`, any other R2 failure -> 503 `unavailable`; then
    `ops_save_media`. Reply `{ ok, id, key, url, created }`.
  - `POST {action:"save_alt"}` -> `ops_save_image_alts`; `POST {action:"delete"}` -> `ops_delete_media`
    (23503 -> 409 `in_use`; the R2 file is kept). Reply `{ ok, id, affects_site: false }`.
- **Client**: `image-prep.ts` re-encodes in the browser (white fill under transparency, long edge 2,560 px, sha256 of the
  sent bytes); `use-media-library.ts` (search after 250 ms, Load more, upload; request counter + loading flag so an
  older reply never lands in a newer list); `MediaPicker` (sheet at 390, dock at 1440); `MediaField` (Choose / Change /
  Remove, and the multi "Add photos" form).
- **Screen** `/dashboard/content/media`: card grid, search, Load more, side panel with EN/AR/ES alt text, "I checked
  this translation" per language, Save, Delete with a confirm dialog.

## Deviations

1. **`lib/ops/media-env.ts`** (extra file): reads `getCloudflareContext().env.MEDIA` and types `FixedLengthStream`;
   the route guard only lets ops routes import from `lib/ops`.
2. **Paging lives in the route**, not the RPC: `ops_list('media')` has no `q`/`after`/`limit`. Gap for 03.2-01
   (below).
3. **Card grid**, not the dense table (owner answer 3).
4. The extra `library` prop drafted on `MediaField` was removed; the field owns its library via `useMediaLibrary`.
5. **Translate slot empty**: 03.2-10's `TranslateButton` is not on main (branch `origin/gsd/phase-3.2-p10`). The slot is
   marked `// 03.2-10:` in `media-library.tsx` and `media-screen.tsx`; `components/ops/media-alt.ts`
   `applyAltDrafts` is ready for its `onDrafts(target, fields)` callback.
6. **Live-section tests** in `host-gate.test.mjs` and `ops-runtime.test.mjs` now assert
   `OPS_LIVE_SECTIONS.includes("/content/media")` instead of a deepEqual, so parallel screen jobs merge cleanly.
7. **Imported photos cannot be deleted** (review finding): Delete is off and shows the "used" message when
   `used_by > 0` or `source === "import"`; the RPC would refuse them anyway (23503, reason `imported`).
8. Client still refuses an original over 15 MB before re-encoding (plan text, signed picture `picker-error-size`),
   though the re-encode could shrink it.
