<interfaces>
API:
- `GET /api/ops/stay-rates?stay_id=` -> `{ ok, stay_id, base_nightly_rate_aed, ranges: [{ id, first_night, last_night,
  nights, nightly_rate_aed }] }` by `first_night`; `&from=&to=` adds `nights: [{ night, nightly_rate_aed, source:
  "range"|"base"|null }]` (max 366, from `stay_night_rates(p_stay, p_from, p_to)` = nights in [from, to)).
- POST `{ action: "set_base", stay_id, base_nightly_rate_aed: "1250.00"|null }`; `{ action: "save_range", stay_id,
  range: { id?, first_night, last_night, nightly_rate_aed } }` -> 409 `rate_overlap` with `detail.conflict_id`;
  `last_night >= first_night`; at most 730 nights; `{ action: "delete_range", id }`. All `affects_site: false`.
- `GET /api/ops/blocks?from=&to=&stay_id=` (window <= 400 days) -> `blocks: [{ id, scope, destination_id, stay_id,
  starts_on, ends_on, reason, created_at }]` including destination and all-scope blocks covering the stay.
- `GET /api/ops/stay-access?stay_id=` -> `{ access: { address, wifi_name, wifi_password, door_code, notes, updated_at } | null }`;
  POST `{ action: "save", stay_id, access: {…} }` (each <= 2,000 chars, null allowed). Never logged.

From 03.2-07: `STAY_TABS: StayTab[]` with `{ key, label(copy), render({ stay, reload, locale }), newStay }`.
From 03.2-13: the Calendar opens its Block dates form pre-filled from `?block=stay&stay_id=<uuid>` (ops host
`/calendar`, dev preview `/dashboard/calendar`).
Kit: `DateRangeField` (inclusive first/last ISO days), `opsFetch`, `opsSend`, `errorText`.
</interfaces>
