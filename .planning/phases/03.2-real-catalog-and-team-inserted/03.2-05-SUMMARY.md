# 03.2-05 summary: Publish rebuilds the public site

A write that reaches the public site (`affects_site: true`) bumps `site_publish.requested_seq` and POSTs the Workers
Builds "Publish" deploy hook. 02-06 can use `requestPublish({ admin })` for the same thing. Workers Builds then builds
only branch `live` with `scripts/build-live.mjs`:

1. A 120 s settle.
2. A read of the sequence, before any content is read, with 03.2-02b's reader on the pinned live host.
3. `assemble --target=production`.
4. Writing `out/site-version.json`, which is served no-store.

The build fails closed before the deploy. The dashboard header shows the signed status line in EN/AR/ES:

- "Up to date · 14:05"
- "Updating since 14:02"
- "Update failed · 14:30 · Try again"
- "Status unavailable"

It compares the database sequence with the live `site-version.json` and gives up after 28 min. When the live file
cannot be read (anything but a 404), the line says "Status unavailable" with no Try again (PR #13 finding 2).
