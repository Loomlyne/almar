### Review findings and fixes

1. **Blocker:** the built-Worker A1 test listed 9 ops routes. Translate is now added as POST only, so A1 (exact list) and A3 (no session gets 403 not_owner) cover it. Fixed in `1e38ca6`.
2. A bare "limit" (rate limit per minute, context limit) showed the daily-limit line. Now only 429 or daily/neuron does. Fixed in `fa81be6`.
3. The button could put drafts translated from stale English onto changed fields, and a throwing `onDrafts` left it stuck on busy. It now copies the English at the click, drops the answers if the English changed or the button unmounted, and ends busy in a `finally`. New test. Fixed in `4bfd283`.
4. When every field was empty the route answered 200. It now answers 400 invalid. Fixed in `de3a72c`.
5. Field names must be lowercase snake_case; this is now documented on the body type for the 06/07/08 screens. Fixed in `c80de94`.
6. Not fixed (low, by design): the shape check does not check the language. If the model echoes the English, it lands as a draft; the owner's "I checked this translation" tick is the guard.
