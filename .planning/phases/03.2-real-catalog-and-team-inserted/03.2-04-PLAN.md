| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-3.2-20 | Elevation | Any `/api/ops/*` | mitigate | `runOps` calls `requireOwner()` first; source guard enumerates every route file and refuses one not built with the wrapper or importing the admin client directly |
