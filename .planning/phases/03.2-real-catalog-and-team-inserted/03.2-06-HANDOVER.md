## Review fixes (PR #18, reviewer agent "ship with fixes", controller items 1-8)
1. **A live item keeps what Publish needs.** On a published item or destination, "Save and update site" waits while a
   fact Publish needs is gone (photo, destination, English name: `liveGaps` in `catalog-forms.ts`), with a line under
   the bar naming it. Arabic and Spanish gaps stay the kit's (it fills or holds them). In a destination's
   Experiences and services, removing a published item's only destination is refused in words before any save
   (`strandedItems`).
2. **Connect loop.** It reads the item list first and applies the owner's change to that list (`connectedAfter`), so a
   destination added elsewhere meanwhile is kept. If a save is refused partway, the Connections card says how many
   saved out of how many, which item did not, and why.
3. **Tests.** Browser: publish refused after a taken save (save first, editor reads back, refusal in words); connect
   stopping on the 2nd save (409 `in_use`); a create whose read-back fails; double-click on Save and on Publish;
   reorder refused (both screens), with the buttons waiting while the order is in flight; live gaps on both screens;
   connect re-read. Node: `saveThenPublish` (save then publish; refused save sends no publish; refused publish keeps
   the id), `saveConnections`, `liveGaps`, `strandedItems`, `connectedAfter`, the price cap.
4. If the read-back after a create fails, the editor keeps the new id, so the next Save updates the item.
5. One Save, Publish, connect or move at a time (a ref guard in each screen). While an order is in flight the list is
   `aria-busy` and a second move is not taken (round 2 dropped the disabled fieldset: it lost keyboard focus). A
   reorder refusal now stays on the list; before, the list read-back cleared it.
6. `normalisePrice`: at most 10 whole digits after leading zeros go, matching the server's `MONEY`
   (`lib/ops/validate.ts`). "0" still gives "0.00".
7. A price that is not money is said as it is typed. Save waits (`canSave`) and Publish waits (the price is in the
   client's missing list), so no AI translate runs with it.
8. Price hint states the format, with no example amount.
- `app/dashboard/(ops)/catalog/persist.ts` (new): `saveThenPublish`, `saveConnections`; both screens use them.
- **Server gap (follow-up, not this job):** `ops_save_*` does not re-check the publish rules on a published row; the
  client guard above is not a substitute.
