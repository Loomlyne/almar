What the pieces do:

- **`build-live.mjs`** is the Workers Builds build command. It refuses any branch but `live`, then settles for 120 s
  (0..600). It reads `requested_seq` with 03.2-02b's `readPublishSequence`, and only after `assertLiveSupabaseUrl` has
  passed. It then runs `assemble --target=production` and writes `out/site-version.json {seq, built_at, commit}`. Any
  failure exits 1 before the deploy command runs. It never runs wrangler.
- **For 02-06:** `requestPublish({ admin })` in `lib/ops/site-update.ts` is the stable rebuild request. An owner endpoint
  built with `opsPost` or `opsPut` needs no call at all: a reply with `affects_site: true` already requests the rebuild
  and carries `site`.
- **`PUBLISH_DEPLOY_HOOK_URL`** is read only in `lib/ops/site-update.ts`. It is never logged and never put in a reply.
  Only `https://api.cloudflare.com/client/v4/workers/builds/deploy_hooks/<id>` is ever called.
