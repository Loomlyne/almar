  `holdOnFailure` are props for the screen to pass.
- `app/dashboard/(ops)/catalog/stays/stay-forms.ts` (pure): `emptyStayForm`, `stayForm` (detail → form),
  `validateStayFacts` (the server's rules: whole numbers, min nights ≥ 1, max ≥ min guests, slug pattern, fee > 0 in the
  server's money format), `lockedLength` / `amenityCounts` (Arabic or Spanish amenities typed by hand must have the English
  line count; server 409 `amenities_mismatch` stays the authority), `stayPayload` (the `save` body: kit B status rule,
  Save keeps each language as it is and Publish sends all published; only changed languages; Arabic/Spanish without a
  title not sent; join sets only when changed or on create; connections split by kind in order).
- `app/dashboard/(ops)/catalog/stays/stays-screen.tsx` (wiring, before the signature): reads `/api/ops/stays`,
  `/api/ops/catalog`, `/api/ops/destinations`, then each stay by `?id=` for the list's connected count (the list reply has
  no ids and a catalog row only a `stay_count`: N + 3 reads; a count on `StaySummary` would make it 3, follow-up below).
  Save sends one `save` with the kit's Arabic and Spanish; Publish with unsaved work (or on a new stay) saves every
  language published, then `POST /api/ops/publish {entity: "stay", id, published: true}`; Publish on a saved page saves
  first only when a language is still a draft; Unpublish; Delete asks first (kit `ConfirmDialog`, the stay's title as the
  line, no new copy), then `delete` and the list again; Move up / Move down and drag send `reorder` with every id, and a
  refusal reads the list again. Errors go to the kit (`error`, so 409 `publish_incomplete`, `parent_unpublished`,
  `amenities_mismatch` are said by the kit's sentences); a failed list read is one alert line above the list. The
  no-nightly-rate warning shows on a published stay with no base rate. `liveTranslations` = the published Arabic or
  Spanish fields with text; `holdOnFailure` stays false (a draft stay is on no page; a published one the kit holds already).
- `lib/copy/ops-stays.ts`: EN / AR / ES. Canvas strings (DashStays) verbatim; the rest are drafts (list below).
