## What is built

  filter, dense table (cards under 768), Move up / Move down and drag; order controls hidden while a search or filter is on.
- `app/dashboard/(ops)/catalog/stays/stay-editor.tsx`: the stay on the kit `EditPage` (kit panel B; the kit is not
  changed). Left: **Text** (English only: title, tagline, neighbourhood, guests / bathrooms / beds / price lines, price
  note; description, amenities, inclusions, policy headings as one-per-line boxes; the kit fills Arabic and Spanish on
  Save, Edit translations opens them), **Photos** (hero required, ordered gallery), **Experiences and services** (one
  picker over both kinds; the destination's own items listed read-only with name and kind). Right (settings): **Place**
  (destination, web address read-only once published), **Capacity** (max / min guests, bedrooms, bathrooms), **Stay
  rules** (minimum nights, default 1, "There is no maximum."; pets Not set / Allowed / Not allowed / Allowed with a fee;
  "Pet fee (AED)" only for the fee case; infants count Not set / Yes / No; no radio). **No price field**: the nightly rate
  is 03.2-15's. Save stays off until an English title; needs ("Choose a destination.", "Enter a web address.", "Enter the
  pet fee…") and the amenities lock are said under the bar; format errors on their field. `liveTranslations` and
  `holdOnFailure` are props for the screen to pass.
- `app/dashboard/(ops)/catalog/stays/stay-forms.ts` (pure): `emptyStayForm`, `stayForm` (detail → form),
  `validateStayFacts` (the server's rules: whole numbers, min nights ≥ 1, max ≥ min guests, slug pattern, fee > 0 in the
  server's money format), `lockedLength` / `amenityCounts` (Arabic or Spanish amenities typed by hand must have the English
  line count; server 409 `amenities_mismatch` stays the authority), `stayPayload` (the `save` body: kit B status rule,
  Save keeps each language as it is and Publish sends all published; only changed languages; Arabic/Spanish without a
  title not sent; join sets only when changed or on create; connections split by kind in order).
- `lib/copy/ops-stays.ts`: EN / AR / ES. Canvas strings (DashStays) verbatim; the rest are drafts (list below).
- `tests/journey/scenes/ops-stays.tsx` (8 states, bracket data only, no rate or fee value), `tests/ops-stays.spec.ts`
  (copy gate and picture block with DOM checks), `tests/ops-stay-forms.test.mjs` (16 node tests).
