<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| owner browser → PUT /api/ops/media | Untrusted bytes and headers enter the ops Worker |
| ops Worker → R2 `almar-media` | Writes to the public media bucket |
| ops Worker → Supabase (service role) | `media` and `image_translations` rows |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-3.2-09-01 | Elevation | route.ts | mitigate | opsGet/opsPost/opsPut call requireOwner first; source-guard test; 403 not_owner |
| T-3.2-09-02 | Tampering | PUT (CSRF) | mitigate | Origin must be the ops origin (wrapper); SameSite cookies (job 02) |
| T-3.2-09-03 | Tampering | upload of a non-image or a renamed file | mitigate | Type allow-list; server sets contentType; browser re-encodes; key extension from the type, never from the file name |
| T-3.2-09-04 | Tampering | overwrite of a live photo | mitigate | Content-addressed key; `head` before `put`; R2 `sha256` integrity; no delete of R2 objects |
| T-3.2-09-05 | DoS | large bodies, CPU on Free | mitigate | 15 MB cap before reading; stream to R2; controller measures a 10 MB upload on preview with `wrangler tail` (A5) and moves the path into the Worker wrapper if it exceeds 10 ms |
| T-3.2-09-06 | Info disclosure | logs | mitigate | No logging of headers, alt text or keys |
| T-3.2-09-07 | Tampering | alt text rendered on public pages | accept | Text only, React-escaped at build |
</threat_model>
