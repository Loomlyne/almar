API (contract):
- `GET /api/ops/destinations` -> `items: DestinationSummary[]` `{ id, slug, name_en, is_published, position, stay_count,
  published_stay_count, hero, translation_state, updated_at }`; `?id=` -> `DestinationDetail` `{ …, hero_media_id,
  inset_media_id, hero, inset, translations: { en|ar|es: { name, short_line, region, summary, nights_label, status } | null } }`.
  POST `save` `{ item: { id?, slug, hero_media_id, inset_media_id, translations } }`, `delete`, `reorder { ids }`.
- `GET /api/ops/stays` list (`StaySummary` has `destination_id`, `title_en`); `?id=` `StayDetail`. Moving a stay =
  POST `/api/ops/stays` `save` with the stay's own facts from its detail, the new `destination_id` and `translations: {}`
  (absent locales are untouched, contract §1.2) — see "Endpoints assumed".
- `GET /api/ops/catalog[?kind=]` -> `CatalogSummary { id, slug, kind, unit, price_aed, is_uae, is_home_pickup, name_en, is_published,
  position, image, destination_ids, stay_count, translation_state, updated_at }`; `?id=` -> `CatalogDetail { …, media_id,
  stay_ids, translations: { en|ar|es: { name, summary, duration_label, status } | null } }`. POST `save` `{ item: { id?,
  slug, kind, unit, price_aed: "…"|null, is_uae, is_home_pickup, media_id, destination_ids, stay_ids, translations } }`, `delete`, `reorder`.
- `POST /api/ops/publish { entity: "destination"|"catalog_item", id, published }` -> `{ is_published, warnings }` or 409
  `publish_incomplete` (`detail.missing`), `has_published_stays`.
- Money is a decimal string ("1250.00") or null both ways; never a float in a request.
