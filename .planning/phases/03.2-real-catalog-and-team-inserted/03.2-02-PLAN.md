| Build (anon key) → Supabase views | Public data only; the build is the only reader |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-3.2-10 | Information disclosure | Service key reaching the build | mitigate | `lib/data` uses only the anon key; secrets test forbids `lib/supabase/clients` and the service key name under `lib/data` |
| T-3.2-11 | Tampering | Truncated reads (row cap) dropping content | mitigate | `.range` paging; parity compares counts |
