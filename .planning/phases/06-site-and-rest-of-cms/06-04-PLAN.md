## Booking terms contract (Phase 4 runs in parallel)

The exact contract, written into the hand-over for Phase 4's lead:

1. `lib/booking/terms.ts` keeps `BOOKING_TERMS_VERSION = "placeholder"` and `BOOKING_TERMS_IS_PLACEHOLDER = true`
   unchanged (they are the closed fallback; tests/booking-link.test.mjs stays green). This plan ADDS
   `export async function bookingTermsGate(db: BookingDb): Promise<{ isPlaceholder: boolean; version: string }>`:
   it calls `db.rpc("booking_terms_current")`; `{published: true, version}` → `{ isPlaceholder: false, version }`;
   anything else, an error, or an unreadable answer → `{ isPlaceholder: true, version: BOOKING_TERMS_VERSION }`
   (fails closed). `BookingDb` is imported as a type from `./server` (type-only import: no cycle at runtime).
2. SQL `public.booking_terms_current() returns jsonb` (defined in 06-01's single Phase 6 migration from this exact
   text; this plan only calls it; service_role only):
   `{published: false}` unless the `booking_terms` row is published AND its en, ar and es translations are all
   `published`; then `{published: true, version: 'cms-' || 16 hex chars of sha256(title + every block text in position
   order, en then ar then es, joined by U+001F)}`. The version changes exactly when the published text changes.
3. Phase 4's call sites (the hold route / `lib/booking/server.ts`, owned by Phase 4) change two lines: the gate is
   `liveGate(secret, (await bookingTermsGate(db)).isPlaceholder)` and the payload stores
   `terms_version: gate.version` (one `bookingTermsGate` call per hold, reused for both). If Phase 4 has landed when this
   plan executes, Task 3 makes these two edits on the controller's slot for `lib/booking/server.ts`; if not, Phase 4
   makes them and this plan touches neither file. Either way Stripe stays in TEST mode until the owner says live.
4. The checkout's terms checkbox label links to `legalPath(locale, "booking_terms")` (from `lib/legal/kinds.ts`) when
   `getPublishedLegalKinds()` includes `booking_terms` at build, else keeps `[Booking terms]`. Phase 4 owns that
   component; this plan only exports the two functions.
