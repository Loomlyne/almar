Guests get share and saved stays (F-12, F-13) on the static public site: Share on every stay page, a heart on every
stay card and stay page, sign-in that saves after return, and a Saved stays list on Account.

<objective>

   else Copy link (`components/ui/copy-link.tsx`, reused as is) and a WhatsApp link
   (`https://wa.me/?text=<stay name + address>`). The address is the stay's canonical `/<locale>/private-stays/<slug>`
   URL (`absoluteLocaleUrl`), never `window.location`.
2. **Saved stays (BOOK-07, F-12).** A heart on the stay cards (home Private Stays, the /private-stays list, the stay
   page's related stays, the blog post's featured stay) and on the stay page. Pages are static files, so the heart's
   state hydrates from `GET /api/saved-stays` (06-01's name), fetched once per page and only when the signed-in hint
   cookie is present. Signed out: the heart is a link to `/<locale>/login?return=stay&stay=<slug>` that also stores a
   save intent; after the sign-in link she lands on that stay page and the save completes. Signed in: `POST
   /api/saved-stays` / `DELETE /api/saved-stays?stay=` with her session cookie, RLS own rows, the Origin rule of
   `/api/preferences`.
3. **Account (F-12).** A "Saved stays" card: published saved stays as cards with Remove; unpublished ones drop out.

Output: copy, five presentational/client parts, one pure rules module, one handler module, one Supabase binding, one
route, wiring on five pages, pictures, three test files (unrun). No SQL.
</objective>

## Contract this plan defines (06-07 only)

| Call | Request | Answer |
|---|---|---|
| `GET /api/saved-stays` | her cookies; no body | `200 { ok: true, signedIn: false }` (no auth cookie, or `getUser()` names no user: never 401, so a stale hint is quiet) · `200 { ok: true, signedIn: true, stays: string[] }` (slugs of her saved, published stays, newest first) · `503 { ok: false, error: { code: "unavailable" } }`. Always `Cache-Control: private, no-store`. |
| `POST /api/saved-stays` | `application/json`, ≤ 256 bytes, `{ "stay": "<slug>" }` | Origin refused → `403 wrong_origin` · bad body or slug → `400 invalid` · no user → `401 signed_out` · not a published stay → `404 not_found` · saved (also when already saved: insert with `ignoreDuplicates`) → `200 { ok: true, saved: true }` |
| `DELETE /api/saved-stays?stay=<slug>` | no body | Origin refused → `403` · bad slug → `400` · no user → `401` · removed or nothing to remove → `200 { ok: true, saved: false }` |
| Login | `/<locale>/login?return=stay&stay=<slug>` | slug passes `isStaySlug` → return path `stayReturnPath(locale, slug)` = `/<locale>/private-stays/<slug>`; any other value falls back to today's cookie path |
| Save intent | `localStorage["almar-save-intent"] = { "stay": "<slug>", "at": <ms> }` | valid for `SAVE_INTENT_TTL_MS` = `RETURN_COOKIE_MAX_AGE` × 1000 (one hour, the return cookie's own life); read once, then deleted |

## Trust Boundaries

| Worker `almar` → `saved_stays` (her session, `authenticated`, RLS) | one guest must never touch another's rows |

| `localStorage` save intent | written by page script; must not let another page make her save |

|-----------|----------|-----------|-------------|-----------------|
| T-06-71 | Spoofing / Tampering (CSRF) | POST/DELETE `/api/saved-stays` | mitigate | `checkPreferencesOrigin` (Sec-Fetch-Site same-origin, Origin equal to the own host) before the body is read; JSON content type only (no simple-form POST); SameSite=Lax session cookies; route test |
