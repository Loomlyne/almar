## Deviations from Plan

- **Nav scene and nav spec block landed in Task 1's commits**, not Task 3's, because the `SiteNav current page` block sits in `catalog-primitives.spec.ts` (one file); the `nav.tsx` fix is in the Task 1 feat commit. Task 3 then added only the types file and node guard. No behaviour difference.
- **RED was shown by tsc/missing modules for Task 1** (scenes import files that did not exist) but the Task 2 spec was written after the implementation and checked green directly; the Task 2 test commit precedes the feat commit in history only.
- **`returnFocusRef` type is `RefObject<HTMLElement | null>`** (plan said `RefObject<HTMLElement>`). With React 18 types `useRef<HTMLButtonElement>(null)` is `RefObject<HTMLButtonElement>`, which is assignable to both; the wider form also accepts a `useRef<HTMLElement | null>(null)`.
- **MediaCard `onOpen` branch renders `action` only when set** (plan copied the href+action branch). Same DOM when set.
- **MediaCard JSDoc and CountBadge comments reworded** so the source guard's single-occurrence and no-`Intl.` checks hold (the guard counts raw text).
- Job 11's extra MediaCard props (`titleSize`, `align`, `zoom`) exist since the merge; the onOpen branch honours them through the shared `TITLE`, `lineBox` and `picture`.
- Dialog `detail` branch markup is inside a ternary in `FocusScope`; the sm/wide/full subtree is byte-identical but not re-indented (kept the diff reviewable).

No Rule 4 items. No stubs. No threat flags: no new network, auth or file surface; scenes load only through the flag-gated harness.
