# Phase 3.3 slice 1 — controller reconcile (2026-10-03)

Plans 03–08 were written in parallel by separate planners. Each flagged what it assumed from the others.
This file settles every overlap. **Where it differs from a plan, this file wins.** Every plan carries a
pointer to the items below that change it. Decided by the controller (`almarprod-website-code-79`);
nothing here changes what the owner signed.

## Waves

| Wave | Plans | Why |
|---|---|---|
| 1 | 01 data layer · 02 shared components · 03 routing, locales, assembler | No dependency between them |
| 2 | 07 media | Needs 01's manifest and `media.ts`; provides `tests/helpers/media-route.ts`, which 04–06 use |
| 3 | 04 home · 05 stays list · 06 stay detail | Need 01, 02, 03 and 07 |
| 4 | 08 preview host, sitemap, final gate, hand-over | Needs all of the above |

The lead merges `origin/main` into the branch before each wave.

## Items

**R-1 Journey store.** `lib/journey-choice.ts` (the sessionStorage Where/When/Who value carried between
pages) is owned by **plan 02**, wave 1, next to the journey bar it serves. Plan 04 drops its conditional copy;
plan 06 imports it.

**R-2 Public page frame.** `components/site/public-frame.tsx` — nav, footer and WhatsApp composed once, with
props for links, `localeHrefs`, `currentPath` and `currency` on/off, and every held control off — is owned by
**plan 03**. Plans 04, 05 and 06 use it; plan 04's `home-nav.tsx` becomes, at most, a thin wrapper.

**R-3 Organisation JSON-LD.** One helper, `components/site/organization-json-ld.ts`, owned by **plan 03**.
Every React page carries it (required by `tests/json-ld-domain.test.mjs`). Plan 04 drops its own copy.

**R-4 One build test runner.** **Plan 03's** `playwright.build.config.ts` over `tests/build/**` is the only
build runner. Plans 04, 05, 06 put their build specs in `tests/build/home/`, `tests/build/private-stays/`,
`tests/build/stay-detail/` and drop their own `playwright.build.config.ts` files; plan 03's `testIgnore`
keeps them out of the dev run.

**R-5 The two job 05 tests.** `tests/stay-pages-no-mariven.spec.ts` and `tests/stay-pages-mariven.test.mjs`
are deleted and replaced by **plan 06** (React guards under new names, 0 Mariven in all 36 built documents).
Plan 08 only re-checks that they are gone and the replacements pass.

**R-6 Phone/tablet switch.** The existing `md` breakpoint (48rem): below it the phone entry and sheet, at and
above it the full journey bar. So 390 shows the sheet; 834 and 1440 show the bar.

**R-7 Home stories.** **Plan 01** adds `stories` (three, with images through `mediaUrl`) to `HomeBlocks` and
to `fixtures/home*.json`, content verbatim from the live home. Plan 04 Task 4 depends on it.

**R-8 Currency with no choice yet.** **Plan 02's** currency select supports "no choice yet": on a first
visit nothing is selected, so choosing AED is a real change. Plan 04 relies on it.

**R-9 Per-page copy files approved.** `lib/copy/home-page.ts` (04), `lib/copy/stays-list.ts` (05) and
`lib/copy/stay-detail.ts` (06) are new files under `lib/copy/`, imported directly, not registered in
`lib/copy/index.ts`. No `lib/copy/public.ts`. AR and ES strings in them are drafts for the owner's review.

**R-10 Price range fix approved.** Plan 04 changes `lib/fx/rates.ts` so both ends of a range convert (today
"Est. USD 21,783.53–90,000" converts only the low end; it is wired to no live page). Money: a fresh Opus
reviewer reads that diff before the hand-over.

**R-11 Assembler and two build folders.** **Plan 03** owns `scripts/assemble-cloudflare.mjs` in wave 1: it
copies the public React pages' `.html` (dashboard, account and login stay out) and `.next/static`, and
writes the three locale 404s. **Plan 08** adds `--target=local|preview|production` in wave 4, calling plan
07's `assertMediaReady()` for preview and production. **The preview builds into its own folder,
`out-preview/`**, and `wrangler.preview.toml` points `[assets] directory` at it; production keeps `./out`.
A preview build never writes `out/` and a production build never writes `out-preview/`, so a wrong
`wrangler deploy` cannot ship preview files (with `noindex`) to the live site. `out-preview/` is gitignored.

**R-12 Runbook gate.** Plan 07's step C10 becomes: `--target=preview` before a preview deploy,
`--target=production` before a production deploy. Never the bare assembler before a deploy.

**R-13 Route counts.** `tests/no-dead-links.test.mjs` and `tests/json-ld-domain.test.mjs` are **plan 03's**:
both compute their route lists instead of asserting 26 Framer pages. Plans 04, 05, 06 do not edit them.

**R-14 `tests/locale-switch.spec.ts` stays unedited.** It tests `/account`, whose cookie switch stays. The
public address switch is tested in plan 03's build suite.

**R-15 Sitemap now.** Plan 08 writes `robots.txt` and `sitemap.xml` in this slice, listing every live page
(the 42 React documents with hreflang alternates plus the remaining English-only Framer pages, counted at
build). This supersedes design §8 SC5's timing; its objection ("14 of 26 would be wrong") no longer applies.

**R-16 Mariven guard scope.** Plan 06's guard scans `app/`, `lib/`, `components/` and `public/`.
`framer-export/canvas-components.json` (not served) still holds the sentence and stays out of scope.

**R-17 `npm run host:cloudflare` is not used.** It runs a bare `wrangler deploy`, which uses the Vamos login
on this Mac (`wrangler.toml` pins the ALMAR account, so it fails rather than deploying to Vamos). It stays
unchanged in this slice; plan 08's hand-over proposes the fix. The controller deploys only with the ALMAR
login.
