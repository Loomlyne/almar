## APIs as built

- `icons.tsx`: `IconProps` now exported. `PoolIcon WifiIcon DropIcon TvIcon AirIcon KitchenIcon FlameIcon BedIcon CalendarIcon PlusIcon PauseIcon PlayIcon`, and `AMENITY_ICONS: Record<AmenityIcon, (props: IconProps) => ReactNode>` (pool Pool, wifi Wifi, water Drop, tv Tv, air Air, kitchen Kitchen, grill Flame, security Shield, parking Car, outdoor Palm, lounge Stay, service Headset, check Check). Line icons (1.5 stroke) except Pause and Play, like Chevron and Search; the plan said "filled", the file mixes both already.
- `button.tsx`: `buttonClass({variant, size, journey})`, `LinkButton({href, variant, size, ...anchor props})` (an `<a>`, `no-underline`, no disabled state). Variants `outline` (transparent, teal text, gold border, `md:text-body`) and `ivory` (ivory ground, teal text, gold border), size `bar-auto` (`h-bar px-8`).
- `section.tsx`: `SectionHead` props `tone: "rule" | "plain"` (default rule, output unchanged), `align: "start" | "center"`; `headingSize` now defaults per tone (heading for rule, display for plain). Plain: kicker `text-label md:text-body text-teal`, heading `text-display`, intro `text-label md:text-body`, block in `<Reveal kind="heading">` (`max-w-2xl`, `mx-auto text-center` when centred), action in `<Reveal kind="button">` at the inline end (start) or under the intro (centre). `Section` prop `variant: "default" | "page"`; page = `grid gap-12 py-16 md:py-section` with a plain head; `id` kept.
- `card.tsx`: `MediaCard` gains `titleSize ("title"|"heading")`, `align ("start"|"center")`, `zoom ("none"|"sm"|"md")` (sm 1.02x, md 1.05x, `motion-safe:group-hover`, `duration-hover ease-reveal`, image in an overflow-hidden box). `PortraitCard({href, image, title, facts?: {icon: ReactNode; text: string}[], className})`: one `<a>`, `aspect-2/3`, gradient `from-ink/70 via-ink/10 to-transparent`, title `text-heading` ivory, facts row `text-label`, photo zoom 1.05x.
- `fact-list.tsx`: `layout: "rows" | "inline" | "plain"` (rows = today), `icon?: boolean | ReactNode` (a node is drawn as given, `true` is still the check mark). inline = wrapped line, no rules; plain = same grid as rows without hairlines or fixed row height.
- `slider.tsx`: `Slider({images, labels, layout, dotsEvery = 1, autoplay = false, className})`, `SliderImage`, `SliderLabels`, `AUTOPLAY_MS = 2000`, `slideOffset(boxes, i, rtl)`. Served HTML: `<section aria-roledescription="carousel">` with a focusable `overflow-x-auto snap-x snap-mandatory` track of N `role="group"` slides, first image eager, rest lazy, no button. After mount: clipped track with inline `translate: <x>px 0` on `duration-slide ease-reveal motion-reduce:transition-none`, previous (inline start) and next (inline end) 44 px buttons, dots (24 px buttons, 8 px square inside, `aria-current`), hidden `aria-live` line ("off" while autoplaying), swipe (|dx| > 40 and > |dy|, mirrored in RTL), ArrowLeft/ArrowRight (mirrored), wrap-around, neighbours of the current slide eager. Autoplay: 2000 ms, paused by hover, keyboard focus-visible and a hidden tab; any manual input sets playing false for good; Pause/Play button only with autoplay and motion allowed; Play clears a resting hover.
- `background-media.tsx`: `BackgroundMedia({poster, videoUrl, className})`; `poster` is a URL string or `{src, alt?}` (empty alt by default). Poster `<img>` is always in the served HTML; after mount, with a video URL, motion allowed and no load error, a muted looping inline `aria-hidden` `<video>` with the poster. The parent must be the positioned box (the component is `absolute inset-0`).
- `journey-bar.tsx`: `action?: ReactNode` (rendered in `<div className="flex shrink-0">` where Search would be, only without `onSearch`; stays `role="group"`). `journey-sheet.tsx`: `finalAction?: ReactNode` (step 3, without `onSearch`, in `<div className="flex min-w-0 flex-1">` in place of Done).

## Deviations from Plan

**1. [Owner change] Accordion not built.** Per the OWNER CHANGE block: no `components/ui/accordion.tsx`, its tests and must-have dropped. `PlusIcon` stays (the plan lists it with the icons).

**2. [Rule 3 - Blocking] `tests/controls.test.mjs` regex.** It forbade `border-gold` in `button.tsx`; the plan's outline and ivory variants draw gold as a 1px border. Changed `/(?:bg|border|text)-gold/` to `/(?:bg|text)-gold/` with a comment (gold stays a line, never a fill or text). The file is in the plan's verify list.

**3. [Rule 3 - Blocking] `app/embed/hero-booker/route.ts` SOURCES.** `tests/embed-sources.test.mjs` follows every import of the hero-booker bundle, `components/icons/icons.tsx` is in it, and the required `import type { AmenityIcon }` made `lib/data/types.ts` reachable. One line added to the SOURCES stamp list (dev cache invalidation only; the import is erased by esbuild). Not a shared-controller file.

**4. Peek slide is 1312 px wide at 1440, not 1280.** The plan says the Framer slide is 1280x718 with 80 px sides but also `px-4 md:px-16` (64 px); `px-20` is off the spacing allow-list in `tests/design-tokens.test.mjs`. I built `md:px-16`, so the slide is 1312 x 738. Plan 45 or the lead decides: widen the allow-list for 20 (controller-gated test) or accept 64 px sides.

**5. Shapes the plan left open.** `PortraitCard.facts` is `{icon: ReactNode, text: string}[]`. `BackgroundMedia.poster` takes a URL or `{src, alt}`; `ImageRef` has `url`, not `src`, so pages map it. `Slider` autoplay is off unless both `labels.pause` and `labels.play` are given. Section/SectionHead `headingSize` default is now per tone.

**6. Sheet slot test is source-level.** `JourneySheet` renders through a Radix Portal, which draws nothing on the server, so the node test pins the source text; the browser probe above covers the behaviour.
