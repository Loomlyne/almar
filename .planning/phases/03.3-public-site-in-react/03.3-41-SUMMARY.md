# Phase 3.3 Plan 41: Motion ground and the one light footer Summary

Motion is declared by markup and tokens only (Reveal wrappers, `data-scroll` hooks, one controller, no package), invisible content is impossible with JS off or reduced motion, and home, list and stay pages share one light footer with the signed content and an Arabic phone number that reads left to right.
