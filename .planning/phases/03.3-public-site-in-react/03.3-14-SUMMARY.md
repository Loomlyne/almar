## Deviations from Plan

1. **[Rule 3] Footer and h1.** `frame.footer` is not in the copy file. The page passes `SITE_FOOTER_COPY[locale]` as `private-stays-page.tsx` and `destinations-page.tsx` now do; the copy test does not pin `frame.footer`. The h1 is `SectionHead headingLevel={1} headingSize="display"` as on `/private-stays`, not a hand-written block.
2. **Filters button has no `aria-haspopup`.** The plan asks for exactly 45 `aria-haspopup="dialog"` buttons (the cards), so the sheet's trigger does not carry it. The sheet itself is a named dialog.
3. **ItemDetail does not render the kicker.** The kicker is the Dialog's own slot (S2-4), so a static render of `ItemDetail` cannot show it (Radix portals do not render on the server). `overlayKicker` is asserted as a pure function and the browser spec asserts the kicker above the h2 in the open dialog.
4. **Request Inquiry is a `LinkButton` (primary)**, not a bare `Link`, so the bar has a visible next step in the place the board draws Add to cart. Same link, same label, same target.
5. **Filter-state API additions.** `setDestinations` and `setStays` (take the next list from a `CheckboxGroup`) are exported besides the toggles, and `toggleDestination` / `toggleStay` take an optional order argument. Destination chips remove through `setDestinations`, so a stay left outside the checked places is dropped.
6. **Acceptance grep `COP`.** `grep -nE "AED|USD|EUR|COP" lib/copy/experiences-page.ts` matches the export name `EXPERIENCES_PAGE_COPY` ("COP" inside "COPY"); the test uses word boundaries. No currency is in the file.
7. **TDD order.** Task 1: RED shown by moving the file aside, one commit. Tasks 4 and 5: test written first and shown failing, committed together with the code. Task 6's source test was written with the code.
8. **`npm run build` before assemble** was not run separately: `assemble-cloudflare.mjs` runs the build (S2-24); the static listing is from that run.
9. **Shared files:** `KNOWN_DEAD` was edited by removing the plan's 38 entries (subtractive, plan-mandated); every other shared edit is an append or a one-token change (`PUBLIC_PAGES`, `DEFAULT_PATHS`, the `PUBLIC_PAGES` deepEqual, one expected path).

No Rule 4 items. No auth gates.
