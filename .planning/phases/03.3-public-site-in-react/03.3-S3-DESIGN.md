### 2.2 Three extensions

1. **`SectionHead` takes `headingLevel={1}`** (today 2–4). The page title on Contact is an `<h1>` with the
   gold rule and kicker — board 5c's title block, the same as 5h's. Slice 1 wrote that `<h1>` inline in
   `private-stays-page.tsx` because the primitive could not; this makes the primitive able to, so Contact does
   not repeat the inline copy. `private-stays-page.tsx` is not touched here (slice 1's file).
2. **`MediaCard` takes `body?: ReactNode`**: a paragraph under the title, body size, ink colour. Today the card
   has only a muted one-line `detail`; the six About cards carry 25–60-word paragraphs. Dashboard use: the
   Content › Pages previews.
3. **`Gallery` takes `interactive={false}`**: the same grid with no buttons and no lightbox, images only. The
   five intro photos are decorative (`alt=""`); a lightbox on an unnamed picture has nothing to announce.
   Dashboard use: the media library's read-only previews. Default stays `true`, so slice 1 is unchanged.

### 2.3 Not built

- No form primitive, no select, no textarea on these pages (the form is held).
- No video component (no video plays).
- No journey bar on About.
- No `ButtonLink`. CTAs are `Link`, as in slice 1.

## 3. The data

Rule, as slice 1 drew it: what carries an image or will be edited as an entity (hero, cards, contact details)
reads through `lib/data`; section headings, intros, labels and meta live in a per-page copy file under
`lib/copy/`, imported directly and not registered in `lib/copy/index.ts` (reconcile R-9). No component imports
a fixture (`tests/data-boundary.test.mjs` already enforces it).

### 3.1 Types (added to `lib/data/types.ts`)

```ts
/** One card of About's Our Story or Our Values. */
export type AboutCard = RowMeta & {
  slug: string;
  /** "story" | "values" — which section the card belongs to. */
  section: "story" | "values";
  title: string;
  body: string;
  image: ImageRef | null;
  is_published: boolean;
  position: number;
};

export type AboutBlocks = {
  hero: { kicker: string; headline: string; image: ImageRef | null };
  intro: {
    statement: string;

    /** The wide still where the live page plays the home video. */
    still: ImageRef | null;
  };
  /** Published cards only, in order. A section with no card is not rendered. */
  story: AboutCard[];
  values: AboutCard[];
};

/** The business's own contact details: Dashboard › Settings › Business and brand (D-92). */
export type ContactDetails = {
  /** "ALMAR Private Journeys" */
  business_name: string;
  /** "Bogotá, Colombia" — translatable. */
  location_label: string;
  location_url: string;
  /** "+971563883302" — tel: and wa.me are built from it. */
  phone_e164: string;
  /** "+971 56 388 3302" — shown as published. */

  whatsapp_message: string;
  instagram_url: string;
```
