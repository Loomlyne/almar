## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL query -> page state | `?type`, `?destination`, `?stay`, `?item` are visitor-controlled text read after mount |
| Page -> other origins | links in the overlay and the nav; images from the media host |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-3.3-14-01 | T | `?item=` / `?destination=` / `?stay=` tampering | mitigate | parseCatalogQuery then stateFromQuery keep only values in the server-supplied slug sets; a slug is only compared, never written into the DOM as HTML; unknown values are dropped (node matrix in Task 2, bad-input browser cases in Tasks 7 and 8) |
| T-3.3-14-02 | S | Overlay links pointing off-site | mitigate | stay hrefs and the inquiry href are built on the server with localePath / siteHref from fixed paths; the client never builds an href from the query string |
| T-3.3-14-03 | R | A held control rendered disabled or hidden (cart, Add, price, Login) | mitigate | source greps (Tasks 3, 5, 6) plus count-0 browser assertions with menu, overlay and sheet open, per locale and width (Task 8) |
| T-3.3-14-04 | I | Third-party hosts on the page (Framer CDN) | mitigate | the Framer route is deleted; built-document and request-log checks for framerusercontent, catbox, pexels; every img on MEDIA_BASE_URL |
| T-3.3-14-05 | I | Invented service or price text reaching visitors | mitigate | every name and paragraph comes from plan 10's fixtures (published text); no price field is read; copy test forbids currency and price words |
| T-3.3-14-06 | D | Focus lost or trapped after closing the overlay or sheet | accept | low impact; focus return is asserted in Tasks 7 and 8 |
</threat_model>
