`slide`), A12 hover zoom uses `duration-hover ease-reveal` (plan 42). Reveal adds no transform after reveal, so a
revealed wrapper never becomes a containing block for fixed or sticky descendants; still, never wrap a sticky or
fixed element in a Reveal — put the Reveal inside it.

Scroll formulas (measured; 1440 stay hero and 390 home hero agree):
- fadeOpacity(scrollY, h) = clamp(1 − (scrollY − h/2) / h, 0, 1)  — 1 until half the hero has scrolled, 0 at 1.5 h.
- dropOffset(vh, top, ph) = −ph × (1 − clamp((vh − top) / (vh/2), 0, 1)) — top is the photo's untransformed top in
  the viewport, ph its height (Framer: −360 px at the bottom edge, 0 once it reaches mid-screen).
