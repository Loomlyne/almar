**New exports, tests/helpers/site-links.mjs** (this plan; plans 13-17 use them):
- `REDIRECTS_FILE = "public/_redirects"`
- `parseRedirects(text) -> { rules: Rule[], errors: string[] }`, `Rule = { line: number, from: string, to: string,
  status: number, splat: boolean }`; never throws; an error names the line number and the reason.
- `readRedirects(file = REDIRECTS_FILE) -> { rules, errors }`; a missing file is `{ rules: [], errors: [] }`.
- `matchRedirect(rules, pathname) -> Rule | null`: the FIRST rule whose `from` equals `pathname`, or whose `from`
  ends in `/*` and `pathname` starts with the part before `*` and is longer than it.
- `sitePages() -> Set<string>`: Framer page paths plus every React public route, trailing slash dropped except "/"
  (exactly no-dead-links `:24`).
- `hasRoute(path, { pages = sitePages(), rules = readRedirects().rules, publicDir = "public" } = {}) -> boolean`:
  a matching rule is followed first (redirects run before assets), and then only if its destination pathname is
  a page or a public file and matches no rule (one hop); otherwise a page or a public file.
- `JOB_04_ADDRESSES`: the English addresses the live site answered at job 04 (history; it never grows): "/",
  "/about", "/blog", the 3 posts, "/contact", "/destinations", "/experiences", "/private-stays", the 12
  `/private-stays/<slug>` of locale-routing `STAYS`, "/services" and the 3 `/services/<slug>` with route files.
- `siteInventory() -> { framer, englishReact, redirected, doubled, unanswered }`: `redirected` = rule sources
  that are page addresses (no splat, no trailing slash); `doubled` = paths served as both a Framer and a React
  page, or a page that a rule source shadows; `unanswered` = JOB_04_ADDRESSES entries where `hasRoute` is false.
- `resolveInOut(outDir, pathname)` gains two answers, checked FIRST against `<outDir>/_redirects`: `"rule"` when a
  rule matches and its destination pathname resolves `"ok"` and matches no rule; `"rule-broken"` otherwise.
