## Deviations from Plan

1. **[S3-29] Sizes.** The plan's 88/56 px (48/32 px on a phone) are 64/40 and 48/32 here: hero h1 and Get In Touch h2 are `--text-hero`, section and Contact h2 are `--text-display`, each asserted equal to the page's own token and to the literal 64/40 and 48/32.
2. **[Rule 1] `tests/build/slice1-sweep.spec.ts` edited (not in the plan's file list).** Its sitemap test hard-codes 42 `x-default` links; adding About and Contact makes it 48. Changed to `DOCUMENTS.length + 3 * 2` and retitled; the check that the 42 sweep documents are listed and each answers 200 is untouched. The file is plan 08's and shared: the lead may prefer another form.
3. **[Rule 3] One new shared helper, `tests/build/slice3-pages.ts`** (not in the plan's file list), so the About and Contact specs do not duplicate the open, measure and frame checks. It imports `tests/build/stay-detail/_helpers.ts` (unedited).
4. **Held `<select>`.** The plan says no `<select>` anywhere. Every document holds one: the header language select's hidden native twin (`aria-hidden`, 1 px). The byte test asserts none in `main` and exactly one in the document; the held specs assert none outside `<header>`. The language select is itself a rendered control, tested by clicking it.
5. **Images outside main.** The plan allows only the nav wordmark; the light footer's wordmark is a `data:image/svg+xml` `<img>` (slice-1 fix, plan 41), so the footer's is allowed too. `main` holds no `data:` or `/_next/static/media/` image, as the plan says.
6. **About h1 position.** The plan's "in ar the h1 sits at the inline end" belongs to the old left-aligned design; the page is centred, so the spec asserts the centre within 2 px in every locale.
7. **A10 at 80 %, not 50 %.** At half the hero height the hero photo's opacity is still 1; the fade (job 11's A10) has not begun. The spec checks above 0.95 at the top and below 0.9 at 80 % of the hero, as plan 23's dev spec does.
8. **Frame tests are split.** The plan has one frame item; here: wordmark, nav and footer Pages (test 4 / 6), language row and select (5), skip link (6), footer email, phone, Instagram and the float (7). `/destinations` and `/experiences` are Framer pages with the same address in English, so "localised" is decided by `matchPublicPage`, never by comparing hrefs (my first version clicked into a Framer page and the Framer CDN requests failed the test).
9. **The plan's literals** `Start Your Inquiry` in all three languages are a regex in `contact-held.spec.ts` (the copy file does not hold the string yet, plan 26 adds it).
10. **Test counts.** About: 9 + 1 held tests per context (90). Contact: 9 + 1 held (90). The plan's "27 contexts per spec" holds for each spec file.
11. **Plan 25's other instructions that no longer apply** (reported): no `homeHref` passed (slice 1 fixed it); slice 2's `publicDocuments()` is not on the base, so S3-30's additive media-lib edit was already done by plan 22.
