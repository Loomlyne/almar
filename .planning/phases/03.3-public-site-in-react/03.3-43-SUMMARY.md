## Deviations from Plan

1. **[Rule 3] tsc red between commit 1 and 2.** Plan 1 removes `stays.count`, `gallery.open/close/count`, which the page and the old spec read until Task 2/3.
2. **[Rule 1] gallery column.** The strip's wide track made the one-column auto grid 5024 px wide and pushed the centred head off screen; fixed with `grid-cols-1` (4d0aff1).
3. **Bar role.** With `onSearch` the bar is a `role="search"` form, not a group; the spec uses getByRole("search"). The plan text said group.
4. **Test 3b on a phone.** Step 3 with no dates cannot be reached (the sheet checks each step on Next), so the phone case asserts `sheet.warn.where` on step 1 and `sheet.warn.when` on step 2 and that Search is not offered, instead of "warn.when on step 3". The desktop cases are as planned (error.both, error.dates).
5. **Test 4/5 extras.** `5b` (docked gone at the top) split from 5; the old "docked has no submit" assertions became "docked Search goes to the list".
6. **Stays grid.** `md:grid-cols-3` (three cards from md, as the must-have says) rather than the `md:grid-cols-2 xl:grid-cols-3` of the action text; the third card is `hidden md:block`.
7. **Test 10 images.** Two non-media images are allowed (the nav wordmark repo file and the footer data: URI), not one: the plan only named the footer. Lazy strip slides not yet requested (empty currentSrc) and display none pictures are skipped; the spec scrolls through the page first.
8. **Test 7 swipe.** Starts and ends on photos 220 px in from the edge, mirrored in Arabic: with a mouse, a drag that ends over an arrow button never reaches the track's pointer handler (touch has implicit capture, so real phones are fine).
9. **Built check on the dev server.** The comparison screenshots come from `next dev` on 3085 (the shell refused another `assemble-cloudflare.mjs` run, see below); same source, so layout only.
10. No `<noscript>` form, no `globals.css` edit, as the plan says.
