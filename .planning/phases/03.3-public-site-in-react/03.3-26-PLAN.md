## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> POST /api/contact | Every field, header and the body size are attacker-controlled |
| route -> Resend API | Server-only key; the payload builds an email that lands in the owner's inbox |
| Resend -> inbox | The visitor's text is shown to the owner; reply goes to the visitor-supplied address |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
