04-08 SQL, all `security definer`, execute for service_role only, called with `owner.admin.rpc(name, args)`:
- `ops_lapse_holds()` -> int. 04-08 replaces 04-02's function with the same signature and grants (P-09 as changed
  2026-10-20): it lapses only requests with no recorded payment (`paid_fils = 0`) whose deadline passed more than 2 minutes
  ago (they get the lapse email, as before); it skips `awaiting_payment` requests with `paid_fils > 0` and, in the same
  call, flags each of them whose deadline passed more than 2 minutes ago (`needs_attention` true, `attention_reason`
  `deadline_passed_part_paid` when the reason is null, one `needs_attention` event `{ reason: "deadline_passed_part_paid",
  paid_fils, deadline }`, once per deadline); it returns the number lapsed (flags are not counted); the cron calls it every
  5 minutes. 04-09 calls it before every list and detail read (04-08 A), before a status change and before a resend.
- `ops_list_bookings({ p_q, p_status, p_destination, p_arrive_from, p_arrive_to, p_after, p_limit })` -> `{ items: OwnerItem[], next: string | null }`.
