# Phase 3.1 Harness-to-canvas report

Plan 03.1-28. Owner checklist for the UAT step "compare the coded harness with the canvas Journey frames" (D-32).
Canvas: https://claude.ai/artifact/6MqV4cd2KzXLsVputN2ctw, page 4 (Journey), repo copies in `.planning/design/2026-09-29-system/pages/journey.dc.html`.
Board names below are the four page-4 boards (README, "Page 4 · Journey"). Frame names are the labels drawn on those boards; where a state has no frame of its own the cell says so.

## How to run the harness

```
ALMAR_HARNESS=1 npm run dev -- -H 127.0.0.1 -p 3010
```

Open the URL in the table, for example `http://127.0.0.1:3010/__harness?c=journey-bar&s=missing&l=en`. Change `l=` to `ar` or `es`. Set the browser window to 390, 834 or 1440 wide. Without `ALMAR_HARNESS=1` the route is a 404 (dev and production).

Baseline images: `tests/journey/__screenshots__/<scene>-<state>-<locale>-<width>.png`. The table lists the English images; swap `-en-` for `-ar-` or `-es-`. `n/a` means the component does not exist at that width (phone-only components skip 834 and 1440; 768-up components skip 390).

## Deviations

Recorded in plans 19 to 25 and this plan. Expect these when comparing with the canvas.

- Guest picker is centred under the Guests tab, not end-aligned (plan 24, D-70 over the plan text). Panels on tablet take the bar's full column width.
- Phone sheet has no safe-area inset (bottom padding is `pb-4`); the guardrail bans arbitrary values. A safe-area token is a Phase 4 follow-up (plan 25).
- Phone sheet dialog title is an sr-only paragraph, not an h2, so the only h2 is the focused question (plan 25).
- The done-step check on StepRail is the 16px CheckIcon (icons ship 16/20/24), not 14px (plan 20).
- The Done and Clear row of DateRangePanel and GuestPanel is dropped inside the phone sheet (`footer={false}`); the dock button replaces it (plan 25).
- Fixture text is bracketed on purpose: `[Short line]`, `[Name]`, `[Role]`, `AED [PRICE]`, `AED [AMOUNT]`, `[RATE]%` (D-39, D-52). The canvas uses the same strings.
- AR and ES copy is still the draft flagged for owner review (D-08). The Arabic month names come from the browser locale; dates and booking references stay Latin inside `<bdi>`.
- `hero-booker` (legacy embed) keeps its hard-coded DESTINATIONS; D-33 applies to the new journey components only (plan 23). It is not in this harness.
- Summary bar size (`journey-bar` / `summary`) has no page-4 frame; it is the Phase 4 `/booking/trip` size from the UI-SPEC.
- Scenes with no canvas frame of their own (destination-menu empty and loading, journey-cart loading, journey-sheet stay-locked and blocked-when) are compared on copy and behaviour only.
- The docked bar and the phone cart dock are `position: fixed` in the harness; the baseline image crops to the fixed element, so the surrounding page is not shown.
- Found and fixed while writing this plan's specs: the AddOnRow control column was 124px and a stepper needs 132px, so the plus button wrapped under the minus (all three languages, desktop and tablet); it is now 136px. The JourneyCart stay dates were not inside `<bdi>` in Arabic; they are now.
