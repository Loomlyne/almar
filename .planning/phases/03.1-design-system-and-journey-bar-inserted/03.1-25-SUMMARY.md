## Deviations from Plan

- [Rule 3] `ArrowIcon` added to icons.tsx (no arrow glyph existed), as SearchIcon was in plan 24.
- [Rule 3] Optional `footer` prop (default true) on DateRangePanel and GuestPanel so the sheet can drop their Clear/Done row (plan 19 had not exposed it). With `footer={false}` the dates line stays as an sr-only live region and the guest floor line stays as a caption. Desktop behaviour unchanged.
- [Caller] `JourneySheet` also takes `lockDestination` (sheet starts at When, Back on When closes) and `blockedDates` (passed to DateRangePanel) to match JourneyBar (D-62, D-63). `initialWarn` is harness only.
- Dialog title is an sr-only `<p>` (Dialog.Title asChild), not an h2, so the only h2 is the focused question.
- Focus return: there is no Radix Trigger (the entry lives outside), so the sheet records `document.activeElement` on open and restores it on close. If a browser does not focus a button on tap (Safari), focus falls back to the page body.
- Bottom padding is `pb-4`; no safe-area inset (arbitrary value banned by the guardrail). Phase 4 follow-up: add a safe-area token.
- Sheet inner panels override the popover chrome with `shadow-none`, `px-0`, `bg-ivory`.
- Spec measures Back/Close with `toHaveCSS` (bounding boxes were flaky during the slide-in). Tailwind v4 mirrors via the `scale` property, so RTL checks read `scale`.
