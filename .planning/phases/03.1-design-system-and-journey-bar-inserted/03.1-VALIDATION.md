## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | `node --test` for `*.test.mjs`; `@playwright/test` 1.63.0 for `*.spec.ts` |
| **Config file** | `playwright.config.ts` (port `PW_PORT`, default 3010; chromium; `npm run dev` webServer with `ALMAR_HARNESS=1`) |
| **Quick run command** | `node --test tests/design-tokens.test.mjs` |
| **Full suite command** | `npm test` (`node --test tests/*.test.mjs && playwright test`) |
| **Concurrency** | Plans that run Playwright carry `parallel: false`; overlapping runs set `PW_PORT` to a free port |
| **Estimated runtime** | ~5 s quick; full suite several minutes (screenshot matrix) |

## Sampling Rate

- **After every task commit:** `node --test tests/design-tokens.test.mjs`

- **Before `/gsd:verify-work`:** full suite green, plus every canvas page signed off by the owner
- **Max feedback latency:** 5 seconds (quick run)
