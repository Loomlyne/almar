## CSS kept and why
Kept: `@layer theme, base, components, utilities;` (legacy dropped from the order, tokens:check still passes), `@import "tailwindcss"`, both `@custom-variant` lines, the generated `@theme` block, and the whole `@layer base` (phone type sizes, html/body, h1-h3, ::selection, :focus-visible, forced-colors, font faces, Arabic line heights).
Nothing else was kept. Before deleting, every legacy class was grepped across app/, components/, lib/ (route.ts excluded). Framer bridge pages (app/**/route.ts, lib/nextjs-export) are served as standalone HTML responses that never load globals.css, so no Framer styling depended on it. No component used a legacy CSS variable.
Legacy rules with a live user were replaced by utilities, not kept: `.ui-spinner` (motion-safe:animate-spin in Button and SpinnerIcon), `.icon-back/.icon-forward` (-scale-x-100 rtl:scale-x-100, rtl:-scale-x-100 in calendar.tsx and dashboard calendar-screen), `.icon-button` (dashboard calendar nav buttons, same utilities as calendar.tsx). Marker class names (ui-button, ui-chip, field-control, choice, switch, is-on...) remain on components as inert hooks; no CSS selects them.
Dropped without replacement: global `:disabled, [aria-disabled]` colour/cursor rule (components carry disabled utilities; no screenshot or test changed), `html[data-density="compact"]`, `.package-card-name`.
