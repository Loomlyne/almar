## Deviations from Plan

1. **[Rule 1 - Bug] Radix Select ignored RTL.** First AR screenshot showed a left-aligned trigger and list. Fixed with an explicit `dir` on Select.Root.
2. **[Rule 3] Option list z-index is z-70, not z-45.** The list is portaled and must sit above the z-50 phone menu; 45 would render underneath it.
3. **[Rule 3] Header breakpoint 1152px instead of 1088px.** Guardrail forbids arbitrary container values; `@6xl` is the nearest standard step above the old width.
4. **[Rule 1 - flake] screens helper.** `chooseArabic` clicked Menu before hydration on `/login` at 390px once. Added a retry (`expect(...).toPass`) around opening the Menu. Only that helper was edited.
5. Nav `NavLabels`/HOME_COPY strings unchanged; phase-03-guest existing nav assertions still passed unchanged, one new test added for logos, LocaleSelect and footer contact.
