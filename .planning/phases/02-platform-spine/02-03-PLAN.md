|----------|-------------|
| Cookie almar-locale → html dir | Untrusted cookie must only select en, ar, or es |
| Browser token → verifyEmailToken | Untrusted token, verified by the package or ignored |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-02-09 | Spoofing | email-verification token | mitigate | Call verifyEmailToken only if that package was approved and installed. Otherwise ignore the token. Do not hand-roll the check. Do not add a typed code. |
