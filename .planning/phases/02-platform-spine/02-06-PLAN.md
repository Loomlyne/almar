</objective>

Settings route is the ops host path `/settings`, rewritten internally. It is not `/ops/settings`. A guest or a logged-out request does not render the form.

Logo bytes go in `site_settings.logo_bytes`. Do not create a storage bucket. Do not call `.storage`. Max logo 1 MB. MIME `image/png` or `image/jpeg` or `image/webp` only. The public header reads the logo through a server route that checks the owner is not required for the public read of the saved file, and that route does not return `logo_bytes` from the anon-selectable view. The view `site_settings_public` still omits `logo_bytes`.

Contrast uses relative luminance. Text under 24px needs 4.5:1. The 32px heading and non-text boundaries need 3:1. A failing pair blocks save. The line is `The contrast is too low.` Do not auto-adjust the hex.

Service role stays in `lib/supabase/clients.ts`. The settings client component must not import that admin helper.
</interfaces>
